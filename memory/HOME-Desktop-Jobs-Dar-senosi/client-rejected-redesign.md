On 7 November 2026 the user showed the client the redesign on the test copy. The client did not like it at all and had imagined "something more intresting". The user asked whether Shopify allows any stack (Vite, React, headless) and then asked for advanced reference websites that fit Dar Senosi.

**Why:** the quiet, marketplace-first direction (see [[homepage-sections-restraint]]) read as too plain to the client. That memory records the user's earlier preference, which the client has now overruled.

**How to apply:** don't default to restraint for new directions. Show bolder references and samples (immersive storytelling, 3D, motion, sound) and let the client pick before building. The restrained theme on the test copy stays as it is until a new direction is chosen. Keep the standing rules unchanged: never touch the live theme or checkout.
