The `logo` folder started as logo assets only (SVG/EPS/PNG). On 2026-09-06 a Next.js 16 (App Router, TypeScript, Tailwind v4, src/ dir) app was scaffolded into it alongside the assets, with three, @react-three/fiber, @react-three/drei and @types/three installed. Goal: recreate the AppStruct logo as an animated 3D sphere, inspired by https://vanlent.dev. Phase 1 (2026-09-06) is built: src/lib/logoMark.ts (SVG-to-points sampler), src/lib/sphereShell.ts, src/components/LogoSphere.tsx (plain PointsMaterials, spinning shell + rocking mark slab, crown in gold), lab page at /lab. Approved direction: bone dots on obsidian, gold only on the crowning diamond, mark inside the shell as a rocking slab, no wordmark ever. Phase 2 (2026-09-06) done: custom ShaderMaterials in src/lib/shaders/{noise,shell,mark}.ts — simplex-noise breathing on the shell (noiseAmplitude prop, default 0.06), depth shading bone-front/ash-back, warm gold rim on the lit side, mark far-half dims toward ash. Phase 2b (2026-09-06) done: dots made into tiny hard specks (then halved again on user request: shell uSize 0.0052, mark 0.006, 1px floor, hard-edged circle, shell 60k / mark 28k, jitter 0.02; still 60fps). Then, from a reference crop the user supplied, the shell switched to a golden-spiral LATTICE layout (sphereShell.ts latticeShell, shellLayout prop, default "lattice", 40k points, zero jitter, uniform 1px dots, opacity 0.75) with broad smooth lobes only when calm (noiseAmplitude 0.10, frequency 1.1, speed 0.25; fine octave only under turbulence). This is the approved dot look; do not go back to random scatter unless asked. The mark then got the same treatment: sampleMarkLattice() in logoMark.ts places dots on a 45°-rotated lattice over the linework (flat slab, uniform 1px dots, inside cells at 2x pitch, dimmed), pitch derived from the shell spacing via a markDensity prop (default 2.5; at 1.0 the thin lines were too sparse to read). markCount prop was removed. User then found the dot mark barely visible and asked for shiny/brighter with a better gold: accent default changed to champagne gold #C9A961 (was #8F7A56), dot mark got 1.8px dots, density 3 and a shine sweep (uShine), AND a second rendering was added: markStyle="solid" (src/components/SolidMark.tsx) — SVG path extruded with bevel via SVGLoader, bone lattice + gold crown as MeshPhysicalMaterial, lit by a drei Environment of Lightformers plus neutral lights. Lab page has a solid/dots toggle (default solid). User has NOT yet chosen between dots and solid., and scroll-driven turbulence: useScrollTurbulence hook inside a Scene component measures scrollY per frame, eases up in ~80ms and settles in ~1.2s, feeds uScroll + uAgitation to both shaders (noise amplification, faceting by coarse grid cell, fine shiver). Lab page is 500vh with a live turbulence readout (onTurbulence prop). Verified 60fps and a smooth 0→1→0 curve. Next: user review, then Phase 3 (pointer interaction / tuning) and finalising. Note: the embedded Browser pane throttles requestAnimationFrame when hidden, so FPS cannot be measured there.

A local Vite+React clone of vanlent.dev (with R3F + three, plus captures and an audit.md) lives at `../new web/vanlent-dev/vanlent-dev/site` and is a useful reference for the sphere effect.

**Why:** The user described the Next.js project as already existing, but it did not; it was created to match their stated setup.
**How to apply:** Treat `logo` as the Next.js project root. Dev server runs via `.claude/launch.json` config `next-dev` on port 3000. Look at the vanlent-dev clone before writing sphere code. See [[appstruct-brand-assets]].
